# Lab: Property-based Invariants

Lab chạy bốn nhóm property với pseudo-random generator có seed: Money, discount, stock và booking overlap.

```bash
php run.php 20260802 500
```

Kết quả phải in seed và số case. Hãy cố tình đổi điều kiện overlap hoặc bỏ currency check để xem runner tìm counterexample.
