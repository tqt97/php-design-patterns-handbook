# Playground

Khu vực thực hành quan sát: drill nhỏ giúp nhìn dependency direction; flagship playground là mini-application CLI có workflow, failure và test.

## Cách sử dụng

- Với drill: dự đoán output, chạy code, thay implementation và thêm assertion.
- Với flagship: theo dõi state transition, idempotency, failure handling và log.
- Không coi playground là production template; hãy đọc giới hạn trong từng bài.

## Quality checklist

- Nội dung phải đúng với mục tiêu của thư mục và có liên kết điều hướng rõ.
- Ví dụ hoặc lời giải phải nêu invariant, failure path và trade-off.
- Không dùng tài liệu tra cứu nhanh thay cho việc hiểu context của pattern.  
> **Ngữ cảnh áp dụng:** Khi thực hành **Playground**, ghi lại output trước/sau và chỉ ra một dòng code chứng minh boundary đã thay đổi.
